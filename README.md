# Farrukh Ali Qazi — Static Portfolio

## Open
Open `index.html` in a modern browser. No build step, React, or npm installation is required.

## Files
- `index.html` — complete responsive site (HTML, CSS, JavaScript in one file)
- `assets/portfolio-reference.png` — supplied design reference, if available

## Before publishing
1. Replace the hero portrait placeholder with your approved profile image.
2. Add your resume PDF at `assets/Farrukh-Ali-Qazi-Resume.pdf` to activate the resume download links.
3. Verify phone, email, LinkedIn URL, employment history, and project descriptions.
4. The page uses Google Fonts when internet is available; it falls back to system fonts offline.
